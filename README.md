# 🚀 endless-builder-activity-dashboard

**endless-builder-activity-dashboard** is a **frontend-only demo dashboard** created to conceptually
visualize the **Endless Bi-Weekly Developer Contribution Program**.

This project is **not a fully functional production system**.  
It is a **design and interaction demo** intended to demonstrate how builder activity, progression,
and submissions *could* be presented in a real Endless application.

---

## ⚠️ Demo Disclaimer

This dashboard is a **conceptual demo only**:

- ❌ No backend or database
- ❌ Submissions are not persisted
- ❌ Builder data is static (`data.js`)
- ❌ No real validation or moderation logic

The purpose of this project is to showcase:
- UX flow
- Visual hierarchy
- Program alignment
- Developer-facing interaction patterns

---

## ✨ Features

### 🏆 Dynamic Builders Leaderboard (Demo)
- Data-driven leaderboard powered by `data.js`
- Automatic **Top Builder** highlight based on contribution count
- Builder ranking, contribution totals, and contribution categories
- Visual distinction for Builder levels (Gold / Silver / Bronze)

> All leaderboard data is **mock data for demonstration purposes only**.

---

### 📈 Builder Level Progression (Concept)
Builder level explanations displayed on the Home page:

- **Builder 1.0** – Entry-level contributors actively submitting code, docs, or tools  
- **Builder 2.0** – Proven builders with recurring, high-quality contributions  
- **Builder 3.0** – Core ecosystem builders showing leadership and long-term impact  

These levels are **illustrative** and do not reflect live or official assignments.

---

### 📝 Submit Contribution Page (Demo Flow)
- Dedicated **Submit** menu
- Developers can input:
  - GitHub repository link
  - Twitter / X post link
- Submission action is **UI-only** and does not store data

This mirrors the **intended bi-weekly submission experience**.

---

### 📱 Responsive Design
- Mobile-first layout
- Desktop-optimized scaling
- Works across phones, tablets, and laptops
